# 发布归档

## v1.1.5 - 2026-08-08

### 重要变更

- 应用对外品牌正式更名为 **Red Fund**，与原作者项目区分：菜单栏、设置、关于等界面显示名统一为 Red Fund。
- 打包产物（.app 包名、启动台/应用程序文件夹显示名）改为 **Red Fund**，Info.plist 的 CFBundleName 与 CFBundleDisplayName 均更新为 Red Fund。
- GitHub 仓库与发布/更新检查地址切换为 **yoosen/red-fund**（原为作者仓库），发布包名改为 `red-fund-<版本>-<架构>-swift.{zip,dmg}`。

### 功能优化

- 本地用户数据目录由 `~/Library/Application Support/fund-pulse/` 迁移至 `red-fund/`：旧目录在首次启动时会自动整体迁移，老用户数据不丢失。

## v1.1.4 - 2026-08-08

### 新功能

- 累计收益曲线支持鼠标悬停：移动鼠标实时显示垂直参考线、高亮数据点，以及该日的日期、累计收益、当日收益率与累计收益率。
- 收益曲线时间范围新增「1周」选项，可查看近 7 天收益走势与区间收益。

### 功能优化

- 收益曲线纵坐标补充累计收益率小字；隐藏金额模式下收益率仍可正常显示。
- 收益曲线左上角改为展示「区间收益」（区间内净赚金额），数值随所选区间变化，并按盈亏红绿着色。

### 问题修复

- 移除收益曲线正下方的「正收益/负收益」图例文字及红绿圆点（仅保留起止日期）。
- 移除曲线左侧「¥0」标记与左下角最小值轴标签（仅保留 0 参考线虚线）。
- 修复 QDII 基金（海外净值 T+1/T+2）在北京时间 09:30 前的当日凌晨估算导致历史交易日长期显示橙色估值圆点的问题；非当日的估值记录会在启动/刷新时自动回填为已确认。

## v1.1.3 - 2026-08-05

### 问题修复

- 修复 GitHub Action 打包产物在「设置-支持/关于」页签闪退的问题：SwiftPM 生成的 `Bundle.module` 在 app 根目录查找资源 bundle，与打包时拷贝到 `Contents/Resources/` 的实际位置不一致，导致非本机环境找不到资源而 fatalError 崩溃。新增 `Bundle.fundPulseResources` 统一入口，优先 `Bundle.module`、缺失时回退到标准 `Contents/Resources/FundPulse_FundPulse.bundle`，兼容打包位置差异，且不影响代码签名。
- 修复微信支付方式的闪动。
- 修复 tag-release 工作流「Commit archived release notes」步骤在 tag push 事件（detached HEAD）下 `git push` 失败的问题，改为显式 `git push origin HEAD:main`。
